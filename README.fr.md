## Démarrer en trois étapes

1. Utilisez **Télécharger pour Windows** ci-dessus et installez l’application.
2. Ouvrez **Pinboard** et écrivez dans une note. Le contenu est enregistré automatiquement.
3. Cliquez sur **＋** en haut d’une note pour en créer une autre.

## À vous de choisir

- **Notez vos idées** — écrivez une pensée ou une tâche et déplacez la note où vous voulez.
- **Personnalisez vos notes** — choisissez la couleur, la transparence et la taille du texte.
- **Gardez-les en vue** — placez une note au premier plan ou sur le bureau.
- **Retrouvez-les facilement** — ouvrez les notes par date de création dans le calendrier.

## Questions fréquentes

**Fermer une note la supprime-t-il ?**

Le **×** d’une note la masque. Faites un clic droit sur Pinboard dans la zone de notification de la barre des tâches, puis choisissez **Afficher toutes les notes** pour la retrouver.

**Comment passer en français ?**

Cliquez sur la roue dentée d’une note, puis choisissez **일반 → 언어 (Language Setting) → Français**.

**Puis-je sauvegarder mes notes ?**

Ouvrez **Paramètres → Synchronisation → Exporter** pour conserver les notes et les paramètres dans un fichier ZIP.
