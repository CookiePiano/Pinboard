# Contributing

MIT permits forks, modifications and redistributions. Please identify modified
builds clearly and do not present them as official CookiePiano releases.

Propose changes through a pull request. Run the checks in AGENTS.md, preserve
notes and credentials, and include a regression for security or data-loss fixes.
Do not submit real notes, tokens, private logs or credentials. Use private
vulnerability reporting for security findings rather than public exploit details.

CookiePiano reviews external changes and retains repository/release authority.
PR checks have no release or signing credentials. Workflow, installer, native IPC,
lockfile and toolchain changes receive special attention because they affect the
software supply chain. Passing automated checks does not authorize publication.
