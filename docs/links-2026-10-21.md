# Clickable links in notes

Verified on 2026-10-21 (Asia/Seoul).

- Bare `http://`, `https://` and `www.` addresses in a note are underlined in the link color. `www.` addresses open as `https://`.
- A plain left click opens the address in the default browser through `@tauri-apps/plugin-opener` (`opener:default` already allows `http`/`https`). Drag selection and Shift/Alt-click keep normal editing behavior.
- Detection is ASCII-only, so Korean text written directly after a URL is not included. Trailing sentence punctuation and unmatched closing brackets are dropped; balanced brackets such as Wikipedia's `Pin_(disambiguation)` are kept.
- Detection lives in `src/lib/note/links.ts`; the CodeMirror decoration and click handler are in `src/lib/note/editor.ts`. Links are display-only and are not stored in note data.

## Validation

- `node scripts/test-links.mjs` and `node scripts/test-formatting.mjs`: passed.
- `npm run check`: zero errors and warnings.
- Browser harness (Vite dev server, mocked Tauri IPC, real mouse input): link click sent exactly one `plugin:opener|open_url` call with the correct URL; drag selection inside a link and a click on plain text sent none; a newly typed URL was decorated immediately. This is frontend verification, not a live native-app session.
- `scripts/release.ps1`: rebuilt the top-level `Pinboard.exe` and installer; their SHA-256 hashes match the build outputs. The Linux package was not rebuilt.
