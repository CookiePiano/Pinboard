## Portable ZIP backups

The export/import controls sit immediately below the storage choices. Export waits for open editors to save and writes `Pinboard_YYYY-MM-DD_HH-mm-ss-SSS.zip` to the Windows Downloads known folder, including redirected Downloads locations. Dates use KST. Repeated exports receive distinct names and do not overwrite an earlier backup.

The versioned archive contains full note text, inline formatting, background images and opacity, colors, creation/update dates, deletion markers, font/theme/language/shortcut preferences, window size/position/pin/visibility, startup preference, AI app selection and the MCP enabled preference. Embedded images travel with the archive. No app note-count limit was added. The reader accepts one `pinboard.json` entry with a 2 GiB decoded size bound and validates the complete payload before touching current data; it never extracts archive paths.

Import replaces the current note collection and settings immediately. It pauses synchronization, flushes editors, excludes concurrent writes and creates a ZIP of the previous state under `import-backups` in the app data directory. A staged replacement and durable restore journal allow rollback after an interrupted file replacement. Window editors are recreated using the restored state. Off-screen positions fall back to an accessible monitor position using the existing placement rules.

The target PC retains its device ID, account credentials, MCP provisioning grant and runtime files. Import never provisions MCP on an unconfigured PC. An enabled preference is restored only on an already provisioned PC. OAuth credentials and external AI application configuration files are not exported. A missing cloud folder disables sync and displays a reconnect message; restored notes remain local. An unavailable shortcut or OS startup operation reports an error before the note replacement, preserving the existing data. Installed font files are not copied; the app's existing font fallback still applies.

AI app selection is persisted in `ui-preferences.json`, included in the file transaction and reloaded when the AI section opens. Legacy browser-local selection remains readable until a persisted preference exists. Isolated verification does not change the real Windows startup registration.
