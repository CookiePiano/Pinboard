# Calendar and explicit MCP setup update — 2026-10-21 KST

This release implements the seven requested follow-up changes and updates the portable executable and installer in the project root.

## Changes

1. The AI introduction explains that work uses MCP connections to AI applications on the current PC. The exact Korean acceptance string is preserved as a UI contract: `현재 PC에 사용 중인 AI 앱과 MCP 연결을 통해 작업을 수행합니다.`
2. Calendar dates load compact note cards, with titles capped at 80 Unicode characters and body previews at 240, plus an ellipsis when truncated. The visible card body is limited to three lines. Clicking a card opens only that note without rearranging or resizing other notes. Empty dates show an empty-state message. List payloads exclude background image and formatting data.
3. MCP setup is explicit and local to each PC. The connection switch starts disabled. Opening the app or the AI settings page does not create an MCP directory or worker. The Set up MCP action prepares the bridge and persists `provisioned: true`; the connection switch then becomes available but stays off. Legacy automatically generated settings do not count as explicit setup. Already provisioned PCs can resume their worker after restart. AI client configuration files are not edited by this operation.
4. Note headers use pointer capture and position-only native movement. Windows Aero Snap sizing is bypassed, while work-area and note-edge snapping remain. Note maximization and native title-bar double-click maximization are disabled. Resizing remains available through the resize grip and borders.
5. Selection formatting is always available. Obsolete enable/disable flags in older settings are ignored. General settings retain only the size step and highlighter color, with yellow, green, blue, pink, purple and orange presets plus a custom color picker.
6. A note created from another note inherits the source note's background image and image opacity, as well as its tint, opacity and size. Text and text formatting are not copied. Creation without a source uses the latest surviving note.
7. Task-list settings and interactive checkboxes were removed. Existing text, including literal `- [ ]` and `- [x]` sequences, is preserved. Untouched welcome notes migrate to ordinary bullet text.
