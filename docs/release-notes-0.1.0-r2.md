# Pinboard 0.1.0 — 수정 배포본 r2

**설정 창의 X 버튼을 눌러도 창이 닫히지 않던 문제를 수정했습니다.**
앱 버전과 설치 파일 이름은 **0.1.0**을 유지합니다. `r2`는 수정 배포본을
구분하는 표시입니다. 기존 `v0.1.0` 릴리스의 파일은 변경하지 않습니다.

- `Pinboard_0.1.0_x64-setup.exe`를 새로 다운로드하세요.
- 실행 중인 Pinboard를 알림 영역에서 종료한 뒤 설치하고 다시 실행하세요.
- 기존 0.1.0 위에 재설치할 수 있으며, 메모와 설정을 유지합니다.
- 한국어를 기본으로 영어·중국어·일본어·프랑스어·스페인어 소개와 그림 사용 가이드를 제공합니다.

## English

Fixes the settings window's X button failing to close the window. Application and
installer versions remain **0.1.0**; **r2** identifies this corrected distribution.
Download the setup again, quit Pinboard from the notification area, install over
0.1.0, and reopen it. Notes and settings are preserved. Do not reuse the original
v0.1.0 download. The original immutable release remains available as history.

The settings-only capability now permits the final close operation after pending
edits are saved. Other windows do not gain that permission. This release also
includes six-language introductions and illustrated guides using synthetic notes.

This 0.1.0 correction remains unsigned under the documented signing exception.
Checksums and attestations verify provenance; they are not malware guarantees.
The manifest identifies the exact commit, tag and official build workflow run.
Historical local 0.1.1 development installations must not be force-downgraded.
