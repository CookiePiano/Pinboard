# User-guide screenshots

These PNGs show the actual packaged Pinboard v0.1.0 Windows interface, captured
on 2026-10-22 KST. Korean, English, Simplified Chinese, Japanese, French and Spanish
editions each contain six views: a note,
appearance controls, pin modes, calendar, general settings and backup controls.

The application executable matches the official release manifest:
SHA-256 `6fedaa07f616f3ba48dc85636af3090cd44af30e364782ed164e1bb6111861c0`.
Screenshots were captured from its WebView2 content via an isolated CDP session.
They illustrate controls, not native desktop blur, window stacking or installation.
No interface elements were generated, composited or replaced.

Each language used separate task-owned note data and a separate WebView2 profile.
All notes are synthetic examples. No production note data, personal backgrounds,
account credentials or external AI connections were used. The captures include
only application content, not the desktop, taskbar or other applications.

Keep image filenames neutral and captions outside the images. Before publishing
new captures, inspect every image for private content and inspect PNG metadata.
Do not add raw capture logs, profiles or app data to this directory.
