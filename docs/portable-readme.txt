Pinboard 0.1.0 - Windows 11 x64
Corrected distribution: v0.1.0-r2 (settings X close fix).

Official source and downloads: https://github.com/CookiePiano/Pinboard
Extract this ZIP into a folder you can write to, then run Pinboard.exe.
WebView2 is required and normally included with Windows 11.
If missing, obtain it from https://developer.microsoft.com/microsoft-edge/webview2/
Notes are stored in %APPDATA%\dev.pinboard.notes, not beside the executable.
Startup and AI/MCP connections are opt-in. Notes and backups are not encrypted.
Pinboard_Uninstall.exe removes only the current user's installed copy; it does
not remove this portable folder or delete your notes.

This initial release is NOT Authenticode-signed. Windows may show an unknown
publisher warning. Do not disable Windows security protections. Verify the
official release's provenance and checksums before deciding to run it.
See the repository's download-verification guide and SECURITY.md.
